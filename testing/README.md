# THƯ MỤC TESTING CHO SRC/ (TESTING SUITE)

Thư mục này phục vụ mục đích kiểm thử tự động cho toàn bộ mã nguồn nằm trong gói `src/`.

Các bài kiểm thử chính thức được tổ chức tại thư mục `tests/` theo chuẩn mực kỹ thuật phần mềm Python (PEP 518, Pytest và Unittest Discovery).

### Cách chạy nhanh Smoke Tests:
```bash
python testing/run_smoke_tests.py
```
Hoặc chạy trực tiếp từ thư mục `tests/`:
```bash
python tests/run_all_tests.py
```
Xem hướng dẫn chi tiết tại [tests/README.md](file:///run/media/tanlee291/DATA/UTH/Deeplearning/course_work_topic_5/tests/README.md).
